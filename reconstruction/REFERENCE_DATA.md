# 参考资料清单

本目录内的工作台照片共 202 张，来自原 `workcell-v4` 的去畸变图像集。文件按源视频编号分目录保存，原文件名不变。`metadata/camera-names.json` 与 `metadata/cameras.npz` 保留图像和相机位姿的对应关系。

照片总计约 429 MiB，已复制到工作树供 Artisan 读取，并在 Git 中忽略以免把原始捕获数据塞进源码提交。`manifest.json` 记录文件名、大小和 SHA256；要在另一台机器复现，需要单独传输 `images/` 目录。

旧工程记录了视觉接受的桌面变换和近似的机器人底座位置。它们只作为本项目的起始布局约束。相机位姿不是物理标定，重建网格并不能证明真实尺寸；台架、电脑、周边桌柜以及机器人支架的尺寸仍需从多视角图像、机器本体规格或实测补齐。

新项目只需 `references/workcell-v4/` 下的照片和元数据。原 NHT 检查点、Gaussian 模型、旧环境 USD 和 Isaac 运行配置没有复制。
